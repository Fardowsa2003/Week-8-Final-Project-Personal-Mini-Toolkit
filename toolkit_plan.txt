PERSONAL MINI-TOOLKIT PLAN

Project Name: Personal Mini-Toolkit

NUMBER GUESSING GAME The program asks the user to guess a secret number between 1 and 10 and tells them whether their guess is correct, too high, or too low. Concepts used: Variables, input, while loop, conditionals, and f-strings.
TO-DO LIST The program allows users to add tasks, view all tasks, and remove completed tasks. Concepts used: Lists, loops, conditionals, input, and f-strings.
SIMPLE CALCULATOR The program allows users to add, subtract, multiply, and divide two numbers. Concepts used: Variables, input, conditionals, arithmetic operators, and f-strings.

EXACT MENU TEXT:

==================================== WELCOME TO MY MINI-TOOLKIT

Please choose a tool:

Number Guessing Game
To-Do List
Simple Calculator
Quit

Enter your choice (1-4):

PROGRAM STRUCTURE:

A while loop keeps the menu running until the user chooses Quit.
If, elif, and else statements direct the user to the selected tool.
A list stores tasks in the To-Do List tool.
Loops allow users to keep guessing and managing tasks.
F-strings display friendly and clear messages.
Invalid choices are handled with a polite error message.

END OF PLAN
