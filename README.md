Personal Mini-Toolkit
Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools in one menu-driven application.

The tools included are:

Number Guessing Game: Allows users to guess a secret number between 1 and 10.
To-Do List: Allows users to add, view, and remove tasks.
Simple Calculator: Performs addition, subtraction, multiplication, and division.
How to Run the Program
Install Python on your computer.
Download or clone this repository.
Open the project folder in Visual Studio Code or another Python editor.
Open the terminal.
Run the following command:
bash
python toolkit.py

Follow the menu instructions and select the tool you want to use.

Project Reflection

The hardest part of this project was creating the menu loop and making sure that users could return to the main menu after using each tool. The bug that took the longest to fix was handling invalid inputs without allowing the program to crash. I learned how to use lists to store and manage tasks dynamically. I also improved my understanding of loops and conditional statements. Testing each tool helped me identify mistakes and improve the program. If I had one more week, I would add more tools such as a countdown timer, a name formatter, and a calendar. Overall, this project helped me become more confident in writing Python programs.
